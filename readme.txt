Tags: elementor, history, creative, widget, search

== Description ==
Creativehone History provides a custom Elementor widget that lets you search and display creative history content on your WordPress website.  

This plugin is lightweight, simple to use, and fully integrated with Elementor Free and Elementor Pro. With just a drag-and-drop, you can add the **Creativehone History** widget anywhere on your site and enable history search functionality without writing code.  

**Key Features:**
* Custom Elementor widget named *Creativehone History*
* Search and display history content dynamically
* Works with Elementor Free and Elementor Pro
* Optimized for performance and easy to configure
* Compatible with the latest WordPress version (6.8)

== Installation ==
1. Upload the `creativehone-history.zip` file via the WordPress admin dashboard (`Plugins > Add New > Upload Plugin`).
2. Activate the plugin through the "Plugins" menu in WordPress.
3. Make sure Elementor (Free or Pro) is installed and active.
4. Open Elementor editor.
5. Drag and drop the **Creativehone History** widget onto your page.
6. Configure its settings and display creative history content.
